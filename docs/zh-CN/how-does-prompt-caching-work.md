## 原文摘要

原文说明前缀缓存复用相同起始 token 的计算结果，减少重复预填充；它与复用整份答案的语义缓存不同。

## 面试解析

把稳定的系统说明与工具定义放在前面，变化的用户内容放后面。缓存键还应与模型、适配器、模板及权限隔离策略兼容，不能只按文本近似相似度复用 KV。

## 常见误区与边界

命中要求、最短长度、有效期和价格因服务而异。评估应统计真实命中 token、首 token 延迟和总费用，不把首次写入当作必然省钱。
