## 原文摘要

原文介绍 BPE 如何反复合并高频相邻符号，得到介于字符与整词之间的子词词表。编码新文本需要遵守训练得到的合并优先级。

## 面试解析

区分训练与编码：训练统计语料中的符号对并更新规则；编码使用固定词表和规则，不为每个新句子重新训练。字节级基础符号有助于覆盖未见文本。

## 常见误区与边界

不要把所有 BPE 实现等同于最长词匹配；预切分、特殊 token 和字节回退都会影响结果。跨语言应测每字符或每词 token 数及实际费用。

## 面试追问

为什么英文句子和同义中文句子的 token 数可能相差很大？
