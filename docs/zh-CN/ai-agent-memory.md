## 原文摘要

原文将智能体记忆视为模型外部的存储与检索机制，区分不同生命周期的信息，并强调筛选、更新和避免无差别保存。

## 面试解析

把当前任务状态、跨会话偏好和外部知识分开管理。写入时保存来源、时间和权限，读取时按任务相关性检索；冲突信息需要版本或覆盖规则。

## 常见误区与边界

聊天记录、KV 缓存和长期记忆不是同一层。长期保存会增加隐私、过时信息和错误扩散风险，应支持更正与删除。

## 面试追问

用户纠正了过去的偏好，如何防止旧记忆仍被检索出来？
