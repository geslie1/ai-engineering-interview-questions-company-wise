## 面试解析

分词器把文本映射为 token ID；模型处理的是这些 ID 对应的向量。评估分词器应关注可逆性、未知字符覆盖、特殊 token 和不同语言的序列长度。

## 常见误区与边界

同一模型的训练、推理和计费估算应使用兼容分词器。字符数不能直接当作 token 数，聊天模板也会占用预算。
