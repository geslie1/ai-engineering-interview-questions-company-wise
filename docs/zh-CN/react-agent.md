## 原文摘要

原文介绍 ReAct 将任务判断、工具行动和结果观察交替组织，让系统能根据外部反馈继续推进，而不只生成一次回答。

## 面试解析

工程实现可使用结构化工具调用和显式状态：接收目标、选择操作、验证参数、执行工具、记录结果、检查完成条件。不必依赖解析一段自由文本来驱动真实操作。

## 常见误区与边界

生产可观测性重点是行动、证据、状态和错误，不需要把模型内部推理当作可信审计记录。高风险操作仍由运行时权限和审批控制。

## 面试追问
