## 原文摘要

原文介绍计算机操作智能体通过观察界面、决定下一步、执行鼠标键盘动作并再次观察来完成任务，也比较了界面操作与 API 调用。

## 面试解析

工程上可把每一步记录为观察、意图、动作和结果，并用页面状态或业务数据验证是否成功。坐标、焦点和页面加载状态都会变化，执行前应重新检查关键条件。

## 常见误区与边界

点击成功不代表任务完成。界面文字应作为输入数据处理；删除、支付、对外发送等操作需要匹配用户授权，失败后重试还要避免重复副作用。

## 面试追问

按钮点击后超时，如何判断应该重试，还是先检查操作是否已经生效？
